# DAV Motors — сайт

Статический сайт, сделанный по мотивам структуры страницы ProAvto, но с собственным оформлением и текстами.

## Файлы

- `index.html` — структура и формы
- `styles.css` — все стили и адаптив
- `script.js` — меню, модальные окна, интерактив каталога
- `forms.js` — обработка форм
- `assets/logo.jpg` — ваш логотип

## Важно перед публикацией

Формы сейчас демонстрационные: они валидируют телефон и показывают уведомление, но никуда не отправляют заявку.
Для рабочего сайта подключите `forms.js` к вашему backend, Telegram-боту, CRM или почте.

Изображения автомобилей в карточках сейчас загружаются с Unsplash. Для коммерческого размещения лучше заменить их на собственные/лицензированные изображения.


## Реальная отправка заявок

Добавлен FastAPI backend в папке `backend/`. Формы отправляют POST `/api/lead`, а backend пересылает заявку на `6loki@mail.ru` через SMTP Mail.ru.

Пароль от почты не хранится в коде: используется `.env`. В репозиторий `.env` добавлять нельзя.

Инструкция находится в `backend/README.md`.

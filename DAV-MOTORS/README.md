# DAV MOTORS — информационная витрина

Версия от 04.10.2026. Исходный дизайн, логотип, телефон и разделы сохранены.

## Что изменено

- Удалены обе формы, окно обратного звонка, forms.js, FastAPI, /api/lead и SMTP.
- Кнопки подбора ведут к блоку связи: телефон, Telegram и WhatsApp.
- Все пять фотографий и пять начертаний Inter находятся в assets; автоматической загрузки ресурсов Google и Unsplash больше нет.
- Внешние ссылки получили rel="noopener noreferrer". Referrer-Policy: no-referrer предотвращает отправку адреса страницы при переходах.
- Нет счётчиков, пикселей, cookies, localStorage или sessionStorage.
- CSP ограничивает загрузку ресурсов сервером сайта, запрещает сетевые вызовы из JavaScript и отправку форм. HTTP-заголовок дополнительно запрещает встраивание сайта в iframe.
- Удалены шаблонный ИНН и неподходящий текст политики. Страница data.html объясняет работу витрины; это информационная страница, а не полноценная политика оператора персональных данных.
- Вместо Python-приложения — статическая раздача через Nginx. В предоставленной конфигурации отключены access- и error-логи с запросами посетителей.
- Исправлены пути Docker-сборки и Compose. SMTP-пароли и .env не нужны.

## Быстрый просмотр

Распакуйте архив и откройте index.html в браузере. Интернет для просмотра страниц не требуется; он нужен при переходе в мессенджеры.

Если браузер ограничивает загрузку локальных ресурсов, откройте сайт через локальный сервер. Для просмотра с конфигурацией Nginx из этого проекта:

```bash
 docker compose up --build -d
```

Откройте http://127.0.0.1:8000. Порт привязан к локальному интерфейсу; для публикации используйте российский сервер и HTTPS-прокси с доменом.

Остановка:

```bash
 docker compose down
```

## Публикация на статическом хостинге

Загрузите только index.html, data.html, styles.css, script.js и каталог assets целиком. README, LAUNCH.md, VALIDATION.md, Dockerfile и nginx.conf в публичный каталог загружать не нужно.

Выберите размещение в РФ. На обычном хостинге настройки nginx.conf из архива автоматически НЕ применяются: проверьте конфигурацию сервера у провайдера. Meta-CSP и meta-referrer работают из HTML, но защита от встраивания задаётся HTTP-заголовками.

## Перед запуском

Прочитайте LAUNCH.md: там перечислены сведения и настройки, которые нужно подтвердить на реальном сервере.
